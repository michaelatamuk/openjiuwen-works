# Presentation: openJiuwen Works

> Working folder for the product story and the eventual PowerPoint. It lives inside `docs/` but is
> working material, not reader documentation.

## Goal

Make a smart, skeptical audience understand four things:

1. what Works is, in one picture;
2. why the problem it solves is real;
3. how it compares with a harness, a horizontal app and an agent factory;
4. why "just add these modules to X" is not the same product.

The final deliverable is a PowerPoint in this folder. The files below are the raw material: the
brief, the narrative, the comparisons, the objections, the evidence and the demo.

## Audience

Working assumption: product and engineering leadership, partners and technical buyers who already
know agents, harnesses and coding tools. They will ask "why not Orbit?", "why not Devin?", "why not
add a queue and a proof page to our agent framework?".

## One line

**Harnesses run a turn. Orbit organises work. Works delivers a proven change.**

## Rules

- One idea per slide.
- Every comparison is honest; no straw men.
- A claim without a source in [06-sources.md](06-sources.md), a demo step or a test is cut.
- Proposed integrations are drawn as proposed, never as built.
- The deck sells understanding, not a feature list.
